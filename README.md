# دعوة خطوبة أحمد وسام

موقع ثابت (HTML) بدون أي خطوات بناء.

- `index.html` — الدعوة (تتغير رسائلها تلقائيًا: قبل / قبلها بيوم / يوم الخطوبة / بعد 12 بليل)
- `guests.html` — أداة إنشاء روابط الضيوف ورسائل الدعوة والتذكير والشكر
- `song.mp3` — الأغنية
- `og.jpg` — صورة المعاينة في واتساب

الإعدادات في أول `index.html` داخل `CONFIG`:
`siteUrl` و`uploadUrl` و`photosUrl` و`clipsUrl` و`guestbookUrl`.

للنشر على GitHub Pages: Settings ← Pages ← Deploy from a branch ← main ← / (root) ← Save.
